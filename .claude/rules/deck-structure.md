# Deck structure

Treat `index.qmd` as the storyboard: its rhythm, titles, scripted lines and transitions are
deliberate talk design, not incidental markup.

Keep each slide's `timing-duration` aligned with this timed outline:

| Section | Budget |
|---------|--------|
| Intro | 2:00 |
| X1 — Every number computed | 2:30 |
| X2 — One source, every format | 1:45 |
| X3 — Ready to publish | 1:45 |
| Y — Fix it once | 1:30 |
| Z — And next | 2:30 |
| End | 0:30 |

The spoken deck totals 12:30; the remainder of the 15-minute slot is margin.
