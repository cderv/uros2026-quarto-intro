# Deck structure

Treat `index.qmd` as the storyboard: its rhythm, titles, scripted lines and transitions are
deliberate talk design, not incidental markup.

Keep each slide's `timing-duration` aligned with this timed outline (the deck as trimmed and
accepted on 8 November):

| Section | Budget |
|---------|--------|
| Intro | 1:35 |
| X1 — Every number computed | 2:05 |
| X2 — One source, every format | 1:20 |
| X3 — Ready to publish | 1:45 |
| Y — Fix it once | 1:30 |
| Z — And next | 1:50 |
| End | 0:30 |

The spoken deck totals 10:35. 12:30 is the ceiling (the timing bar is set to it); the rest of the
15-minute slot is margin. If a timed rehearsal comes in under 11:00, give time back to existing
slides; never restore a cut slide.
